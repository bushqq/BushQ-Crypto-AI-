# Use multi-model consultation

每次分析同时调用多个模型，让它们基于同一市场快照彼此隔离地生成独立分析，再由一个模型形成唯一的综合裁决。选择会诊而非单模型切换或多数投票，是为了保留不同模型的推理差异，同时避免向用户输出多套互相冲突的结论。

裁决使用不参与第一轮分析的专用跨供应商模型，以降低自我裁决和同源偏差。默认使用 `gpt-5.5`，仅在独立分析出现严重分歧时升级到 `gpt-5.5-pro`；第一轮分析模型当前配置为 `DeepSeek V4 Pro`、`Claude Opus 4.8` 和 `Grok 4.5`，具体型号允许随配置调整。

## Consequences

系统必须区分独立分析与综合裁决，保留每个模型的原始结论和分歧；面向报告、推送及后续交易计划的下游功能只消费综合裁决。系统还必须显式判定严重分歧，不能让升级裁决依赖人工猜测。
